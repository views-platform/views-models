\textbf{One folder per model.} Inside each: thirteen Parquet files --- a columnar table format
that opens in one call from both Python (\texttt{pandas.read\_parquet}) and R
(\texttt{arrow::read\_parquet}) --- named \texttt{\dots\_00} through
\texttt{\dots\_12}, and a short text file recording when the model ran, which version of the
software produced it, and which configuration it used.

\textbf{The thirteen files are thirteen forecast origins}, stepping forward one month at a time. An
origin is the last month the model was allowed to see; from there it forecasts the next 36 months.

Within every file the earliest month is horizon 1 and the latest horizon 36, so a given target
month sits at a different horizon in each file containing it. Metrics computed per origin keep
those apart; metrics pooled across origins mix them.

\textbf{Each file holds 2,333,448 rows} --- 36 months $\times$ 64,818 cells --- and five columns.

\textbf{\texttt{priogrid\_id} is a cell, not a coordinate.} PRIO-GRID is a
$720 \times 360$ grid of half-degree cells covering the globe, numbered from 1 in the
south-west corner and running east before north. To place a row on a map:

\begin{table}[h!]
\centering
\renewcommand{\arraystretch}{1.3}
\caption{Converting \texttt{priogrid\_id} to the centre of its cell.}
\label{tab:priogrid}
\begin{tabular}{@{}p{4.6cm}p{9.4cm}@{}}
\toprule
\textbf{Quantity} & \textbf{From \texttt{priogrid\_id}} \\ \midrule
Row (south to north) & $\texttt{row} = \lfloor (\texttt{priogrid\_id} - 1) / 720 \rfloor$ \\
Column (west to east) & $\texttt{col} = (\texttt{priogrid\_id} - 1) \bmod 720$ \\
Latitude  & $-90 + (\texttt{row} + 0.5) \times 0.5$ \\
Longitude & $-180 + (\texttt{col} + 0.5) \times 0.5$ \\
\bottomrule
\end{tabular}
\end{table}

\noindent In R, for a data frame \texttt{d}:

\begin{quote}
\ttfamily\small
d\$lat <- -90  + (((d\$priogrid\_id - 1) \%/\% 720) + 0.5) * 0.5 \\
d\$lon <- -180 + (((d\$priogrid\_id - 1) \%\%  720) + 0.5) * 0.5
\end{quote}

\noindent The coordinates are cell \emph{centres}; each cell spans $0.5^\circ$ in both
directions. As a check, \texttt{priogrid\_id} 148759 --- the cell discussed in
Section~\ref{sec:caveats} --- resolves to $13.25^\circ$N, $39.25^\circ$E, in Tigray.
The 64,818 cells delivered here are the land subset of the 259,200 in the full grid.

\textbf{Units are fatality counts.} A value of 2.4 means 2.4 fatalities; values are continuous
rather than integer. The transformations applied during fitting are intended to be inverted
before these files are written, so no back-transformation should be applied to them;
Section~\ref{sec:transforms} states what is and is not established about that.

\textbf{Observed values are not included, and are not needed from here.} Evaluation joins these
forecasts to observed fatalities on \texttt{month\_id} and \texttt{priogrid\_id}; the
ensemble tool retrieves those itself, and they are otherwise available from the
datafactory. The file naming used here already matches what that tool expects.

Nine models $\times$ thirteen origins = \textbf{117 files, about 2\,GB} in total.
