# views-baseline first: tests/test_algorithm_coherence.py reads the first
# non-comment line as this source's engine, and main.py imports views_baseline.
# >=1.5.0 so that one floor covers every model in the moving-window set: 1.5.0 is the
# release that added RollingPooledConflictology for the three *_sailcloth models
# (views-baseline #165), and they share this environment prefix. RollingConflictology,
# which THIS model names, arrived earlier — but a prefix resolving to 1.2.0 would leave
# its co-tenants naming an algorithm the registry cannot build.
views-baseline>=1.5.0,<2.0.0
# Declared DIRECTLY, not left to views-baseline. views-baseline 1.0.2 declares
# views-pipeline-core>=3.0.0,<4.0.0 — a floor BELOW the 3.2.0 that can find
# configs/config_maturity.py. An env holding exactly 3.0.0 satisfies that range, so the
# launcher upgrades nothing and the run dies on a missing config_deployment.py (#594).
views-pipeline-core>=3.2.0,<4.0.0
# Floored at 1.17.0: every release 1.9.0..1.16.0 declares `views-frames<2` as a BASE
# dependency with no extra marker, which makes views-frames 3.x unreachable for anything
# sharing this environment. 1.17.0 widened it to `<4` (views-datafactory#527).
views-datafactory>=1.17.0,<2.0.0
